Exercise: Hand Redirection in VR

Prerequisite

Please follow this guide to set up your environment for developing VR.

Hardware

  • 2-3 students share one Quest.
  • USB 3 cable (for building the apk from Unity directly to the headset)
  • The Quest should be in developer mode.

Software

  • Unity 2022.3 LTS
    • Install Android Build Support
    • We often need to download and manage packages/libraries (for example, Meta SDK for developing Quest). To make our life easier in this exercise, please use this link.
  • SideQuest allows you to install your apk to the Quest. SideQuest also provides a real-time view.
  • Meta Quest link: If you use the Windows computer with a good graphic card, you can consider setup the Quest link to make the VR development on Unity easier.
  • Meta Quest XR Simulator: This is a new tool provided by Meta. I haven’t tried but perhaps it’s worth a shot?

Exercises

Warm-up

  1. Build the apk to your Quest. If you have a powerful Windows computer, you could try to set up the Meta Quest link.
  2. Once enter the VR scene, the first step is often to calibrate the virtual and physical environments. Find the script and check how to calibrate. If you are interested, you can look into calib2() and CalibrationTool.CalibrateFromTag() functions to see what is the difference. Discuss with you teammates.

Basic

After the calibration, you should see a panel with multiple variables that you can interact with raycasting and button click. You can change the parameters and click start - this will trigger one trial. Play around with all the variables and then continue to the following tasks.

  1. Try to Modify the code to develop hand redirection in different axes (\(X\), \(Y\), and \(Z\))?
  2. Control one direction, decrease and increase the discrepancy. What did you observe?
  3. Find the parameter that controls the discrepancy between the virtual and the physical hand. Play with this parameter and discuss your observation.
  4. Now fix the discrepancy and compare hand redirection in three axes and discuss which direction is easier to detect.
  5. Can you make this into a block? Repeating multiple times with randomized offset.
  6. Find the code for recording data (or implement it by yourself). Do several trials and record your data. Plot (and fit) the psychometric function. Discuss and interpret your data with your teammates.

Open-ended

  1. Instead of offsetting the virtual hand position, we can also achieve redirection by rotating the environment. First discuss how this approach could work and then implement it.
  2. Instead of using controllers, develop the implementation with hand tracking.
  3. Instead of reaching to the sphere floating in mid-air, try to use a real physical object. What are the challenges?
